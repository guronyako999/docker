Как устроен этот проект

HTML-файлы упакованы в Docker-образ вместе с Nginx (Dockerfile). Файл docker-compose.yml поднимает два сервиса: веб-сервер (порт 8080 → 80) и PostgreSQL (порт 5433 → 5432). Проброс портов описан в секции ports: каждого сервиса.

  • 1. Сборка образа: docker compose build web
  • 2. Запуск стека: docker compose up -d
  • 3. Открыть сайт: http://localhost:8080
  • 4. Подключиться к БД с хоста: psql -h localhost -p 5433 -U aurora_user -d aurora_db
